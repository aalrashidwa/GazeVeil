# GazeVeil

Facial recognition engine leveraging real-time processing of audio-visual feeds via augmented processing modules.

With GazeVeil, you get a lightweight tool that stays out of your way.

**What you get**

- Facial recognition engine leveraging real-time
- processing of audio-visual feeds via
- augmented processing modules

## Key Features

- Facial recognition engine leveraging real-time
- processing of audio-visual feeds via
- augmented processing modules

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/GazeVeil.git`
2. `cd GazeVeil`
3. Install in editable mode: `pip install -e .`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
